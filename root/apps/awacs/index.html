How does it work?

This is an educational geometry model. Catalogue ranges, RCS values and detection curves are illustrative, not validated aircraft performance.

Terrain from Mapzen / AWS Terrain Tiles is bundled locally in data/terrain/. Global zoom levels 0–5 cover Mercator latitudes ±85.05°. The map renders real elevation at 1× scale. Aircraft altitude is feet above sea level, independent of ground elevation.

Visibility tests the straight chord between two aircraft against a spherical Earth (6,371 km radius), sampling approximately every 2 km. Terrain is decoded from the same local zoom-5 Terrarium tiles used by the map, approximately 2.5–5 km pixel spacing at low to middle latitudes. Narrow ridges may be missed. No atmospheric refraction, clutter, electronic warfare, aspect or weather model is included.

The overlay samples up to 3° bearings and 10 km radial steps, at the reference altitude. Green means line of sight; purple means masked or below terrain; grey means missing elevation. The dashed arc is instrument range, not airframe endurance range. Target results also apply field of view, slant range, RCS and the catalogue function.

Catalogue detect(dist, rcs) functions return detection probability P_d from 0 to 1, using slant distance in kilometres and RCS in m². Smooth logistic curves retain the fourth-root RCS range scaling: the previous lock range corresponds to P_d = 90%, and the previous detection range to P_d = 50%.

LOCK: P_d ≥ 90% (red glow). DETECT: 50% ≤ P_d < 90% (yellow glow). LOST: P_d < 50% (grey dot). These are illustrative confidence cutoffs, not a validated tracking model. Results are deterministic; no random detection trials or scan history are simulated. Terrain masking, instrument range and field of view force P_d to zero; missing data or invalid curves leave P_d unknown.

Heading is clockwise from true north. A 270° field is centred on heading. A 360° field is unaffected by heading.

Place any number of AWACS (up to 500 aircraft total). Each target combines all AWACS probabilities using P_d combined = 1 − ∏(1 − P_d), assuming independent detections. Shared blind spots can make this assumption overoptimistic. Missing data leaves the combined probability UNKNOWN unless a known source gives 100%. The displayed slant distance is to the nearest AWACS. Yellow lines connect aircraft with confirmed geometric line of sight, even outside radar range or field of view; use the checkbox to hide them. Coverage is cached per AWACS position, altitude, radar sector and reference target altitude. Moving a target does not recalculate coverage. Overlapping coverage is merged: visible green takes precedence, then unknown grey, then masked purple. Shading describes geometric visibility, not combined detection probability.

Export Scenario downloads a JSON file with aircraft positions, altitudes, headings and map settings. Load Scenario replaces the map after validating the file. Aircraft use the current local catalogue. Clear Map removes all aircraft. Scenario files retain AWACS placement order.

Data or curve failures are shown as unknown, never treated as confirmed visibility. Changes save in this browser automatically. WebGL and a static HTTP/HTTPS server are required. Flags load from FlagCDN; map, terrain, fonts and scripts are local.
